# 整頁改成圖錄頁 設計

日期：2026-11-17
建立在第一版之上：`docs/superpowers/specs/2026-11-17-hand-slit-design.md`

## 意圖

現在的頁面像一個工具：左側控制面板、黑框按鈕、滑桿、狀態列，都是軟體的語言。作品要放在網路上讓人自己打開來玩，使用者希望整頁看起來像一件藝術作品，而不是軟體。

## 目標與非目標

- 目標：整頁沒有任何一個元素長得像軟體介面；打開就知道怎麼玩
- 目標：載入圖片、取得成品這兩件事仍然做得到，因為沒有人在旁邊幫忙
- 非目標：改掃描、追蹤、匯出的行為
- 反目標：變成說明很多的網頁；擬真過頭變成小遊戲

## 方向的選擇

| 方向 | 取捨 | 結果 |
|---|---|---|
| A 展牆：只剩作品、牆上小標、會淡出的一行操作字 | 最安靜；第一次打開的人不容易知道能做什麼 | 不採用 |
| B 工作桌：整頁是桌子，參數寫在便條卡上 | 場景感強；擬真容易做過頭 | 不採用 |
| C 圖錄頁：作品集跨頁，素材和成品是圖 1、圖 2，操作在頁底一行 | 整頁是出版品的語言，打開就懂 | **採用**（使用者選擇） |

## 做法的選擇

| 做法 | 取捨 | 結果 |
|---|---|---|
| 只換皮：保留一整塊 canvas，圖說用 JS 定位貼上去 | 改動小；圖說是假排版，手機直排難對齊 | 不採用 |
| 頁面變成真正的文件：標題、兩個 figure、頁底 footer，版面交給 CSS grid | 改動較大；版面、圖說、手機直排都是正常 HTML | **採用** |

## 頁面

**使用者決定的：** 圖錄頁方向；左欄只放極短的玩法說明，不放創作論述。

```
HAND SLIT        ┌────────┐        ═══════════ 槽
舉起雙手捏住，    │ 圖 1   │        ┌────────┐
兩手之間就是      │ 素材   │        │ 圖 2   │
掃描線。滑鼠也    │        │        │ 成品   │
可以拖曳。        └────────┘        └────────┘
                 圖 1　素材          圖 2　成品，1790 × 2560，掃描中 34%
[鏡頭]
(▶) 已暫停
──────────────────────────────────────────────────────────────
每幀寬度 4 px　平滑 65%　直向 橫向       載入圖片　清除　匯出 PNG　JPEG
```

**我的決定（可推翻）：**

- **成品是主體**（使用者決定）：素材縮小放進左欄，成品在右邊佔滿高度、水平置中
- **左欄**：標題 HAND SLIT、一句玩法、圖 1、最底下是播放鍵和一個很小的鏡頭畫面
- **圖 1**：素材、手部點、掃描線。畫布比圖片大一圈，線頭跑出圖片外時仍看得到
- **圖 2**：成品從槽裡滑出來的印刷品，跟現在一樣，只是槽割在紙面上而不是桌面上
- **圖說帶狀態**：載入手部模型、沒有鏡頭、圖片無法讀取寫在圖 1 的圖說；掃描中、已暫停、已滿和百分比寫在圖 2 的圖說。掃描中那幾個字是紅色
- **頁底一行**：所有參數和操作都是文字。數字在上面左右拖曳就會改，也可以聚焦後用方向鍵；直向 / 橫向目前的是黑色、另一個淡灰；不能用的操作淡灰
- **錄製鍵**（使用者決定）：左下角一顆大的圓形播放鍵。錄製中是紅底白色暫停符號，暫停時是黑框黑色播放三角形，旁邊寫「錄製中 / 已暫停」。手機上浮在畫面左下角，不顯示文字
- **快捷鍵**：不變，Space、C、S。播放鍵旁邊淡灰的「空白鍵」提示
- **字體**（使用者決定）：一律黑體 Noto Sans TC，從 Google Fonts 載入，沒網路時退回系統黑體
- **顏色**：紙白底、墨黑字、灰色圖說；紅色只用在掃描線和錄製狀態
- **手機**：單欄往下排，標題、圖 1（最多約四成畫面高）、圖 2、頁底一行

## 架構上的改動

- `index.html`：改成 header、兩個 figure（各有 figcaption）、footer
- `style.css`：重寫
- `view.js`：p5 畫布只負責圖 1；每幀依兩個 figure 的大小放置畫布與印刷品，並把圖說放在圖片正下方
- `ui.js`：按鈕和滑桿換成文字和可拖曳的數字；狀態分寫到兩個圖說
- `main.js`：狀態訊息拆成「素材」和「成品」兩段
- `geometry.js`：`layoutStage` 改成單張圖版用的 `fitPlate`

掃描、追蹤、平滑、匯出不動。

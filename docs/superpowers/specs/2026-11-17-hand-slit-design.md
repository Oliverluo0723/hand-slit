# HAND SLIT（暫名）第一版設計

日期：2026-11-17
背景、前人作品與論述見專案根目錄的 `NOTES.md`。

## 意圖

延續 SCAN STUDIO 的 slit-scan（時間拉扯的影像），但把掃描線交到人手上：鏡頭追蹤手，雙手食指之間的連線就是掃描線，可移動、旋轉、拉長。線每一幀從素材圖片上取一條，貼到成品的下一欄。成品是一張可匯出的高解析靜態圖。

為什麼：原作是「機器掃、人干擾圖片」；本作讓人取代機器的掃描頭，把馬達的規律換成身體的不規律。圖上的每處變形都對應一個真實的手部動作。

## 目標

- 匯入一張圖片，用手持掃描線掃出一張成品，匯出 PNG / JPEG
- 手感不輸試玩版（`spike/index.html`）：線跟手、延遲低、不卡頓
- 成品解析度獨立於螢幕，從原圖取樣
- 沒有鏡頭或追蹤失敗時，滑鼠和觸控仍可完成整個流程
- 架構能在不改動其他模組的前提下，加入：手勢指令、相機素材、臉部參數、其他掃描方式

## 第一版不做

- 相機當素材
- 手勢指令（開始 / 暫停等）
- 臉部表情控制
- 直線以外的掃描方式

## 反目標

- 變形看起來像後製濾鏡。所有變形必須來自取樣過程本身
- 把手的軌跡平滑到看不出是人做的。平滑強度要可調，預設保留一些手感
- 需要安裝或打包才能跑。推上 GitHub Pages 就要能用

## 限制

- p5.js 為基礎；純靜態網站，函式庫走 CDN，不用打包工具
- 需要 localhost 或 https（鏡頭權限）
- 目標瀏覽器：桌面版 Chrome。其他瀏覽器能用滑鼠模式即可

## 做法的選擇

**檔案組織**

| 做法 | 取捨 | 結果 |
|---|---|---|
| A. 單一 HTML | 最簡單，但五段管線擠在一起，加相機和臉部時難改 | 不採用 |
| B. 多個 JS 模組，不打包 | 結構清楚，部署同 A；沒有型別檢查 | **採用**（使用者同意） |
| C. Vite + npm + TypeScript | 工具最完整，但要裝環境和打包，對目前規模偏重 | 不採用；之後可從 B 升級 |

**追蹤函式庫**

| 做法 | 取捨 | 結果 |
|---|---|---|
| ml5.js handPose | 設定最少，試玩版驗證過；只有手部座標 | 備案 |
| 直接用 MediaPipe | 同一套含手部、手勢辨識、臉部表情數值；尚未在本機實測 | **採用**（使用者同意） |

風險處理：開工第一步先只做追蹤模組並確認流暢度。若明顯不如試玩版，退回 ml5，只換 `tracker.js`。

## 架構

每一幀的資料流：

```
tracker ──手的座標──▶ interpreter ──┐
                                   ├─▶ 掃描線端點 + 指令 ─▶ scanner ─▶ output
pointer ──滑鼠/觸控───────────────┘                         ▲
                                                          source
```

```
index.html          頁面骨架、控制面板
style.css           外觀
src/
  main.js           p5 的 setup / draw，串接各模組
  source.js         素材：載入圖片，提供「這個座標的顏色」
  tracker.js        追蹤：鏡頭 + MediaPipe，輸出手的座標點
  interpreter.js    解讀：座標點 → 掃描線兩端點 + 指令，含平滑
  pointer.js        滑鼠與觸控，輸出格式同 interpreter
  scanner.js        掃描：沿線取樣，寫入成品緩衝
  output.js         成品：全解析度緩衝、清除、匯出
  view.js           預覽、掃描線、手部骨架、狀態
  ui.js             面板按鈕與滑桿
```

兩個接縫：

- **素材**只對外回答「這個座標是什麼顏色」。掃描器不知道來源是圖片還是相機。
- **解讀器與滑鼠**輸出同一種格式：掃描線兩端點（或沒有線）加上指令。掃描器不知道輸入來自哪裡。

座標一律用素材的正規化座標（0 到 1），顯示尺寸和成品解析度各自換算。

## 行為

- **掃描線**：雙手時為兩隻食指指尖；單手時為拇指指尖到食指指尖。有手用手，沒手才看滑鼠（按住拖曳拉線）或觸控
- **取樣**：每幀沿線等距取樣，重新取樣成成品的一欄高度，寫入下一欄，前進「每幀寬度」個像素。掃滿即停
- **錄製**：按鈕與 Space 切換；清除、匯出各有按鈕與快捷鍵
- **鏡像**：鏡頭畫面左右翻轉，手往右、線往右

使用者確認的部分：手持掃描線為主軸、第一版只做圖片模式、模組化不打包、用 MediaPipe。

以下是我的決定，可推翻：

- 成品預設 1790 × 2560（沿用 SCAN STUDIO），直向 / 橫向可切換
- 追蹤頻率與繪圖頻率分開，畫面維持 60 fps，以平滑補間
- 手跟丟時暫停取樣，不繼續掃
- 鏡頭畫面中間約 70% 對應整個素材範圍，讓邊緣搆得到
- 外觀沿用 SCAN STUDIO（米灰底、黑線、左側面板），視為同系列
- 面板參數：每幀寬度、平滑強度、方向、解析度
- 鏡頭小預覽放在角落，顯示手有沒有被抓到

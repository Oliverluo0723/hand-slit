# HAND SLIT v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一個瀏覽器作品：用鏡頭追蹤雙手，食指之間的連線當掃描線，掃過匯入的圖片，產出可匯出的高解析 slit-scan 圖。

**Architecture:** 五段管線（source → tracker → interpreter → scanner → output），每段一個 ES 模組。手部追蹤與滑鼠/觸控輸出同一種「掃描線兩端點」格式；素材只提供像素資料。所有座標在模組之間以素材的正規化座標（0–1）傳遞。純邏輯（幾何、解讀、取樣、成品定位）不碰 DOM，用 Node 內建測試跑；鏡頭、畫布、面板在瀏覽器手動驗證。

**Tech Stack:** p5.js 1.9.4（CDN，instance mode）、MediaPipe Tasks Vision `@mediapipe/tasks-vision`（CDN，ES module）、原生 ES modules、`node --test`。無打包工具、無 npm 依賴。

**Spec:** `docs/superpowers/specs/2026-11-17-hand-slit-design.md`（背景見 `NOTES.md`；手感基準見 `spike/index.html`）

## Review Focus

1. **鏡頭被拒絕或沒有鏡頭** → 不報錯、不卡在載入；狀態列顯示「沒有鏡頭，可用滑鼠拉線」，滑鼠流程完整可用。（Task 2、Task 8）
2. **掃描線部分或全部在素材外面** → 界外取樣為黑色，不丟例外、不讀到別列的像素。（Task 4）
3. **兩端點重合**（單手捏合時拇指碰食指）→ 整條取同一個像素，沒有 NaN。（Task 4）
4. **超大圖片**（例如 8000 × 6000）→ 載入時縮到長邊 4096 以內，不當掉。（Task 6）
5. **掃描途中切換方向或直橫向** → 成品清空、位置歸零，不留下尺寸錯亂的殘影。（Task 5、Task 9）

### Task 1: 專案骨架與 geometry

**Files:**
- Create: `package.json`, `index.html`, `style.css`, `src/geometry.js`, `tests/geometry.test.js`

**Interfaces:**
- Produces:
  - `mapCameraToSource(pt: Point, opts?: {mirror?: boolean, gain?: number}): Point`，預設 `mirror: true`、`gain: 1.4`。公式：`u = ((mirror ? 1 - pt.x : pt.x) - 0.5) * gain + 0.5`，`v = (pt.y - 0.5) * gain + 0.5`。不裁切到 0–1。
  - `fitWithin(w: number, h: number, max: number): {width: number, height: number}`：長邊超過 `max` 才等比縮小，結果取整數且至少 1。

### Task 3: interpreter

**Files:**
- Create: `src/interpreter.js`, `tests/interpreter.test.js`

**Interfaces:**
- Consumes: `Hand`（Task 2）、`mapCameraToSource`（Task 1）
- Produces:
  - `slitFromHands(hands: Hand[], mapOpts?): Slit | null`：2 隻手以上 → 取前兩隻的食指指尖（索引 8），標為 `"Left"` 的那隻當 `a`；兩隻標籤相同就照陣列順序。1 隻手 → `a` = 拇指指尖（4），`b` = 食指指尖（8）。0 隻 → `null`。每個點都經過 `mapCameraToSource(pt, mapOpts)`。
  - `createSmoother(): {update(target: Slit | null, k: number): Slit | null}`：`target` 為 `null` → 清掉內部狀態並回傳 `null`；狀態為空時直接跳到 `target`；否則每個座標做 `cur += (target - cur) * k`。回傳值是新物件，不回傳內部參考。
  - `interpret(input: {hands: Hand[], pointerSlit: Slit | null}, mapOpts?): {slit: Slit | null, commands: string[]}`：有手用 `slitFromHands`，沒有手才用 `pointerSlit`。`commands` 在 v1 一律是 `[]`（保留給之後的手勢指令）。

- [ ] **Step 1: 寫失敗的測試** `tests/interpreter.test.js`

```js
import test from "node:test";
import assert from "node:assert/strict";
import { slitFromHands, createSmoother, interpret } from "../src/interpreter.js";

const RAW = { mirror: false, gain: 1 };
const hand = (handedness, thumb, index) => {
  const landmarks = Array.from({ length: 21 }, () => ({ x: 0, y: 0 }));
  landmarks[4] = thumb; landmarks[8] = index;
  return { handedness, landmarks };
};

test("no hands gives no slit", () => {
  assert.equal(slitFromHands([], RAW), null);
});

test("one hand: thumb tip to index tip", () => {
  const s = slitFromHands([hand("Right", { x: 0.1, y: 0.2 }, { x: 0.3, y: 0.4 })], RAW);
  assert.deepEqual(s, { a: { x: 0.1, y: 0.2 }, b: { x: 0.3, y: 0.4 } });
});

test("two hands: index tips, Left hand is always endpoint a", () => {
  const L = hand("Left", { x: 0, y: 0 }, { x: 0.2, y: 0.2 });
  const R = hand("Right", { x: 0, y: 0 }, { x: 0.8, y: 0.8 });
  const expected = { a: { x: 0.2, y: 0.2 }, b: { x: 0.8, y: 0.8 } };
  assert.deepEqual(slitFromHands([L, R], RAW), expected);
  assert.deepEqual(slitFromHands([R, L], RAW), expected);
});

test("smoother snaps on first target, eases after, resets on null", () => {
  const sm = createSmoother();
  const t0 = { a: { x: 0, y: 0 }, b: { x: 1, y: 1 } };
  const t1 = { a: { x: 1, y: 0 }, b: { x: 1, y: 1 } };
  assert.deepEqual(sm.update(t0, 0.5), t0);
  assert.equal(sm.update(t1, 0.5).a.x, 0.5);
  assert.equal(sm.update(null, 0.5), null);
  assert.deepEqual(sm.update(t1, 0.5), t1);          // 重新出現時不從舊位置滑過來
});

test("interpret prefers hands over pointer and returns no commands", () => {
  const pointerSlit = { a: { x: 0.9, y: 0.9 }, b: { x: 1, y: 1 } };
  const h = hand("Right", { x: 0.1, y: 0.2 }, { x: 0.3, y: 0.4 });
  assert.deepEqual(interpret({ hands: [h], pointerSlit }, RAW).slit.a, { x: 0.1, y: 0.2 });
  assert.deepEqual(interpret({ hands: [], pointerSlit }, RAW), { slit: pointerSlit, commands: [] });
  assert.equal(interpret({ hands: [], pointerSlit: null }, RAW).slit, null);
});
```

### Task 4: scanner

**Files:**
- Create: `src/scanner.js`, `tests/scanner.test.js`

**Interfaces:**
- Produces:
  - `PixelSource = {width: number, height: number, data: Uint8ClampedArray}`（RGBA，逐列）
  - `sampleLine(src: PixelSource, slit: Slit, n: number, dest: Uint8ClampedArray): void`：沿 `slit.a → slit.b` 等距取 `n` 個樣本寫入 `dest`（長度 `n * 4`）。第 `i` 個樣本的 `t = n === 1 ? 0 : i / (n - 1)`；像素座標 `px = Math.floor(x * src.width)`、`py = Math.floor(y * src.height)`（最近點取樣）。座標落在素材外 → `0, 0, 0, 255`。alpha 一律寫 255。

const src = { width: 4, height: 4, data: new Uint8ClampedArray(64) };

### Task 5: output

**Files:**
- Create: `src/output.js`, `tests/output.test.js`

**Interfaces:**
- Produces:
  - `Direction = "lr" | "rl" | "tb" | "bt"`（成品被填滿的方向）
  - `stripRect(direction, width, height, pos, thickness): {x, y, w, h}`（純函式）：`pos` 是已填的像素數。`lr` → `{x: pos, y: 0, w: t, h: height}`；`rl` → `{x: width - pos - t, y: 0, w: t, h: height}`；`tb` → `{x: 0, y: pos, w: width, h: t}`；`bt` → `{x: 0, y: height - pos - t, w: width, h: t}`。`t = Math.min(thickness, travel - pos)`，`travel` 在 `lr`/`rl` 是 `width`、在 `tb`/`bt` 是 `height`。
  - `createOutput(opts: {width, height, direction}): Output`
  - `Output.canvas: HTMLCanvasElement`（全解析度，初始填黑）
  - `Output.width`, `Output.height`, `Output.direction`
  - `Output.stripLength: number`：`lr`/`rl` 為 `height`，`tb`/`bt` 為 `width`。就是 `sampleLine` 的 `n`。
  - `Output.pos: number`, `Output.travel: number`, `Output.full: boolean`
  - `Output.write(strip: Uint8ClampedArray, thickness: number): void`：把 `stripLength` 個像素沿垂直於前進方向排列、重複 `t` 次，用 `putImageData` 寫到 `stripRect` 的位置，`pos += t`。已滿時不做事。樣本順序：`lr`/`rl` 由上到下，`tb`/`bt` 由左到右。
  - `Output.clear(): void`：填黑、`pos = 0`。
  - `Output.toBlob(type: "image/png" | "image/jpeg"): Promise<Blob>`，JPEG 品質 0.92。

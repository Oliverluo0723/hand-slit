# HAND SLIT

用手拿著掃描線的 slit-scan 作品。鏡頭追蹤雙手，食指之間的連線就是掃描線；線每一幀從圖片上取一條，貼到成品的下一欄。成品是一張可以匯出的高解析圖，上面的每一處變形都對應一個真實的手部動作。

SCAN STUDIO 的續作：那件是機器掃、人移動圖片；這件是人取代機器的掃描頭。

## 執行

需要 localhost 或 https 才能使用鏡頭。

```bash
python3 -m http.server 8766
```

打開 http://localhost:8766/ ，允許使用鏡頭。建議用桌面版 Chrome。

## 操作

觀眾主要只做一件事：用手拿著線去掃。每幀寬度、平滑、紙的大小都由作者決定，頁面上沒有任何設定。

- **雙手**：兩手都用拇指捏住食指，兩個捏合點之間是掃描線；捏住就掃，任一手鬆開就停
- **單手**：只顯示拇指到食指的灰色虛線，不會掃；要雙手都捏住才開始
- **滑鼠**：在圖片上按住拖曳，按下的點是線的一端
- **觸控**：兩根手指各控制一端
- **不能重來**：掃過的就留在紙上，沒有清除
- **紙滿就結束**：紙的下緣印上日期和花了多久（從第一條到最後一條，停頓也算）。點一下紙就下載 PNG，紙滑離頁面，換下一張圖
- **不拿走**：紙留在原地；重新整理頁面就是新的一張
- **換一張圖**：鏡頭小畫面下淡灰的「換一張圖」，或把圖片拖進頁面。只在還沒開始掃時可以換，第一條掃下去這幾個字就消失
- **關閉鏡頭**：同一行的「關閉鏡頭」會真的停掉攝影機，只剩滑鼠和觸控；這個瀏覽器會記住

沒有快捷鍵。

## 作者的設定

全部在 `src/piece.js`：

- `images`：預設要掃的圖，照順序一張紙一張，到底繞回第一張（觀眾換過的圖只用在當下那張紙）
- `thickness`：每幀寬度（px）
- `smoothing`：平滑程度（0–95）
- `paper`：成品圖的像素大小（不含白邊）

## 圖

`assets/default.webp`：地鐵車窗，攝影 Tate Marss（從 cosmos.so 收藏，原始授權未確認）。**公開前要換成有權公開的圖**：圖現在是作品的一部分，不是觀眾自己帶來的。讀不到時退回程式畫的測試圖。

## 結構

```
src/
  geometry.js     座標換算、版面
  tracker.js      鏡頭 + MediaPipe Hand Landmarker
  interpreter.js  手 → 掃描線、平滑
  pointer.js      滑鼠 / 觸控 → 掃描線
  scanner.js      沿線取樣
  output.js       全解析度成品緩衝、紙的白邊與印記、匯出
  source.js       圖片載入（長邊上限 4096）、測試圖
  view.js         圖 1 的 p5 繪製、出紙槽與紙
  ui.js           玩法文字、提示、鏡頭開關、點紙拿走
  piece.js        作者的設定
  main.js         串接、一張紙的開始與結束
```

函式庫都從 CDN 載入：p5.js 1.9.4、@mediapipe/tasks-vision 0.10.14。沒有打包步驟。

## 測試

```bash
npm test
```

只用 Node 內建的測試工具，不需要安裝任何套件。涵蓋座標換算、手 → 掃描線、取樣、成品定位、印記文字；鏡頭和畫面需要在瀏覽器裡手動確認。

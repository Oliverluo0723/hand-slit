# HAND SLIT

用手拿著掃描線的 slit-scan 作品。鏡頭追蹤雙手，食指之間的連線就是掃描線；線每一幀從圖片上取一條，貼到成品的下一欄。成品是一張可以匯出的高解析圖，上面的每一處變形都對應一個真實的手部動作。

SCAN STUDIO 的續作：那件是機器掃、人移動圖片；這件是人取代機器的掃描頭。

## 執行

需要 localhost 或 https 才能使用鏡頭。

```bash
python3 -m http.server 8766
```

打開 http://localhost:8766/ ，允許使用鏡頭。建議用桌面版 Chrome。

## 操作

- **雙手**：兩隻食指指尖之間是掃描線
- **單手**：只顯示拇指到食指的灰色虛線，不會錄；要雙手都捏住才開始掃
- **滑鼠**：在圖片上按住拖曳，按下的點是線的一端
- **觸控**：兩根手指各控制一端
- 手離開鏡頭或放開滑鼠時，成品停止前進

| 按鍵 | 作用 |
|---|---|
| `Space` | 錄製 / 暫停 |
| `C` | 清除 |
| `S` | 匯出 PNG |

頁面像一張圖錄跨頁：左欄小圖是素材，右邊從槽裡滑出來的是成品。錄製 / 暫停是左下角的播放鍵；其餘設定和操作都在頁底一行文字裡：數字可以左右拖曳或用方向鍵調整，其餘點一下即可。可以載入圖片（也可以直接拖進頁面）、切換直向 1790 × 2560 / 橫向 2560 × 1790、調每幀寬度和平滑程度。

## 結構

```
src/
  geometry.js     座標換算、版面
  tracker.js      鏡頭 + MediaPipe Hand Landmarker
  interpreter.js  手 → 掃描線、平滑
  pointer.js      滑鼠 / 觸控 → 掃描線
  scanner.js      沿線取樣
  output.js       全解析度成品緩衝、匯出
  source.js       圖片載入（長邊上限 4096）、測試圖
  view.js         圖 1 的 p5 繪製、兩張圖版的版面
  ui.js           頁底操作、圖說、快捷鍵
  scrub.js        可拖曳的數字
  main.js         串接
```

函式庫都從 CDN 載入：p5.js 1.9.4、@mediapipe/tasks-vision 0.10.14。沒有打包步驟。

## 測試

```bash
npm test
```

只用 Node 內建的測試工具，不需要安裝任何套件。涵蓋座標換算、手 → 掃描線、取樣、成品定位；鏡頭和畫面需要在瀏覽器裡手動確認。
